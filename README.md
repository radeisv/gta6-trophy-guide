Platinum Engine — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: the official list with a cited guide for every trophy, a roadmap to the platinum, missable flags, PSN count trackers, search and kind filters, a spoiler setting, and saved progress with export and import. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The guide runs entirely from its own files, with no network requests — every guide is built from the official trophy descriptions and cites Exophase and PSNProfiles.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
